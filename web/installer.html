ChainOSCPad Keyboard Web Installer

XIAO ESP32シリーズへブラウザからファームウェアを書き込みます。

Google Chrome / Microsoft Edge などWeb Serial対応ブラウザからUSB接続してください。 書き込み後のキー割り当ては Configurator で変更できます。
